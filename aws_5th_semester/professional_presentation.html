Deployment Process

Phase 1: Infrastructure Deployment

CloudFormation template uploaded and executed. Stack "MyAWSProject" created with all AWS resources (VPC, EC2, RDS, ALB, S3) in 5-8 minutes.

Phase 2: Application Development

Created Node.js application with Express server, MySQL integration, RESTful API endpoints, and professional frontend with contact form.

Phase 3: Containerization

Built Docker image with Node.js 18 Alpine, installed dependencies, configured port mapping (80:3000), and deployed container with restart policy.

Phase 4: Load Balancer Configuration

Configured listener rules for path-based routing (/api/*), set up target groups, enabled health checks, and verified connectivity.

Phase 5: Testing & Validation

Tested all API endpoints, verified database connectivity, submitted test forms, confirmed data persistence, and validated complete end-to-end functionality.

Security Configuration

Load Balancer SG

  • Inbound: Port 80 from Internet
  • Purpose: Public HTTP access
  • Outbound: All traffic

EC2 Security Group

  • Inbound: Port 22 (SSH)
  • Inbound: Port 80 from LB SG
  • Inbound: Port 3000 from LB SG
  • Blocks direct public access

RDS Security Group

  • Inbound: Port 3306 from EC2 SG only
  • Database isolated from internet
  • Private subnet deployment

Application Security

  • Parameterized SQL queries
  • CORS configuration
  • Connection pool limits
  • Input validation

Network Security

  • Private database access
  • Security group chaining
  • Multi-AZ isolation
  • VPC network segmentation
