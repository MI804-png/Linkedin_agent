Chrome Extension Download Extension
How to install
  1. Click Download Extension above
  2. Open Chrome and go to chrome://extensions/
  3. Drag the downloaded .crx file into the extensions page
  4. Click Add extension when prompted
  5. The AutoApply icon appears in your toolbar — click it and log in using your token below

Copy your credentials into the extension popup once installed.

Windows Bot App Download Bot (.zip)
The bot cannot run on the server — it needs your local Windows PC to control a real browser on LinkedIn.
How to set up & run automatically
  1. Click Download Bot (.zip) above and extract the folder
  2. Right-click enable_hibernate.ps1 → Run with PowerShell (one-time setup — adds Hibernate to your Start menu)
  3. Double-click LinkedInAutoApply.exe — enter your LinkedIn email & password on first run
  4. The bot is now scheduled to run every day at 08:30 AM automatically
  5. Each night: click Start → Power → Hibernate instead of Shut Down
  6. At 08:30 AM your PC wakes up, applies to up to 25 jobs, then hibernates itself again ✅
