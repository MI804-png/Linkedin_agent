# LinkedIn AutoApply – Chrome Extension

## How to install (for users)

1. Download this folder (or get the `.zip` from the website)
2. Open Chrome → go to `chrome://extensions/`
3. Turn on **Developer mode** (top right toggle)
4. Click **Load unpacked** → select this folder
5. The extension icon appears in your toolbar

## How to use

1. Click the extension icon
2. Enter your **AutoApply account** email + password (the one you created on the website)
3. Toggle **"Auto-apply daily"** ON
4. Done — the extension will apply to jobs every morning at 8:30 automatically

## How it works

- Runs **inside your own browser** from your home internet connection
- LinkedIn trusts your session because it's the same IP you always use
- Finds jobs matching your keywords, clicks Easy Apply, fills the form, submits
- Reports results back to your dashboard on the website
- No installation of Python or any technical software needed

## Notes

- Your PC and browser must be **open** at 8:30 AM for the scheduled run
- You can also click **"Run Now"** in the popup to apply immediately
- All settings (keywords, CV, location) are configured on the website dashboard
