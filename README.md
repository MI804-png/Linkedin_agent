## 🎯 Quick Start Guide

### 1. Update Your CV (CV_Professional_Template.md)

1. Open `CV_Professional_Template.md`
2. Replace all placeholders:
   - `[Your Name]` → Your actual name
   - `your.email@example.com` → Your email
   - `+1 (XXX) XXX-XXXX` → Your phone
   - `https://github.com/YourUsername` → Your GitHub profile URL
   - `https://linkedin.com/in/yourprofile` → Your LinkedIn URL
   - Add your education, experience, projects, and skills
   
3. **Convert to PDF/Word:**
   - Use [Markdown to PDF converter](https://markdowntopdf.com) online
   - Or export from VS Code with extensions like "Markdown PDF"
   - Keep original .docx format as backup

### 2. Customize Your Portfolio Website

1. Open `portfolio-website/index.html`
2. Find and replace all:
   - `Mikhael` → Your name
   - `your.email@example.com` → Your email
   - `YourUsername` → Your GitHub username
   - `yourprofile` → Your LinkedIn profile ID
   - `yourportfolio.com` → Your portfolio domain (when ready)
   - Add your actual project details and links

3. **Test locally:**
   - Simply open `index.html` in your browser
   - Or use a local server: `python -m http.server 8000`
   - Visit: `http://localhost:8000`

### 3. Deploy Your Portfolio Website (FREE Options)

#### Option A: GitHub Pages (Recommended - Free Forever)
```bash
# 1. Create a new GitHub repository named: YourUsername.github.io
# 2. Push your portfolio-website files to this repository
# 3. Your site goes live at: https://YourUsername.github.io
```

**Step by step:**
1. Create GitHub account (if you don't have one)
2. Create new repo: `YourUsername.github.io`
3. Clone it: `git clone https://github.com/YourUsername/YourUsername.github.io.git`
4. Copy your portfolio files into this folder
5. Commit and push:
   ```bash
   git add .
   git commit -m "Initial portfolio deploy"
   git push origin main
   ```
6. Wait 2-3 minutes, then visit: `https://YourUsername.github.io`

#### Option B: Netlify (Free & Easy)
1. Go to [netlify.com](https://netlify.com)
2. Sign up with GitHub
3. Click "New site from Git"
4. Select your portfolio repository
5. Deploy! Your site gets a URL automatically
6. Custom domain: add in Netlify settings

#### Option C: Vercel (Free & Fast)
1. Go to [vercel.com](https://vercel.com)
2. Sign up with GitHub
3. Import your portfolio project
4. Deploy automatically
5. Get instant custom domain option

## 🌐 Portfolio Website Customization

### Key Sections to Update:

1. **Navigation Bar** - Your name/brand
2. **Hero Section** - Main headline and call-to-action
3. **About Section** - Your professional story
4. **Projects Section** - Your 3+ best projects with GitHub links
5. **Skills Section** - Your technical expertise
6. **Contact Section** - Email and social links

### Adding More Projects:

Copy this block in the projects section:
```html
<div class="project-card">
    <div class="project-header">
        <h3>Your Project Name</h3>
        <a href="https://github.com/YourUsername/repo-name" target="_blank">
            <i class="fab fa-github"></i>
        </a>
    </div>
    <p class="project-description">What this project does and technologies used.</p>
    <div class="project-tags">
        <span class="tag">Technology1</span>
        <span class="tag">Technology2</span>
    </div>
</div>
```
